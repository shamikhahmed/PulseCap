## Owner decisions (locked)

| Topic | Decision |
|---|---|
| Themes | **Light + dark only.** Default = **match device** (`prefers-color-scheme`), user can pin either in Settings. Legacy theme ids (carbon/stealth/…) stay as CSS aliases → dark, but UI offers only 2. |
| Skip day | **Smart decide**: skipping a workout asks the engine — if the missed muscle group hasn't trained in ~7 days, shift the whole weekly map forward one gym day; otherwise keep schedule and note the skip. Always show reasoning. |
| Copy voice | **Confident coach** — short, direct, human, like a good PT texting. No exclamation spam, minimal emoji. |
| Addictive mechanics | **All four**: weekly recap (Sunday 5pm→Monday, dashboard card + archive), streak freeze + milestones (7/30/100), daily check-in ritual (morning card), progress photos (IndexedDB, ~200KB compressed). |
| Photos | IndexedDB (`pulsecap-photos` DB), canvas-compressed ≤200KB, fully offline. |
| Font | Refined **system stack** (SF Pro/Roboto). No custom font download. |
| Tagline | **"Your coach. In your pocket."** — splash + welcome. |
| Weight-log coach | Goal-aware reaction after every weigh-in: congratulate on-track (lose OR gain OR maintain), nudge off-track. |

## Environment / verification recipe

- App = vanilla JS PWA. No build step. Modules in `js/modules/*.js`, engines in `js/app.js`, data in `js/data/`.
- **Browser caches JS/CSS aggressively** (python http.server). To verify changes: bump the port in `Cap-Apps/.claude/launch.json` (876x → next), `preview_stop` + `preview_start`. Yes, really.
- Tests: `npx playwright test --reporter=line` (15 tests; 13 pass 2 skip = green).
- Screen scan snippet (run in page console): iterate `listScreens()`, `go(id)`, assert `#view .screen` innerText ≥10 chars, watch console errors.
- Mobile viewport: resize 375×812 before visual checks.
- Version discipline: bump `VERSION.json` (version + swCache), `sw.js` CACHE const, add `CHANGELOG.md` + `changelog.html` entries. This release: **5.2.0 / pulsecap-v53**.
